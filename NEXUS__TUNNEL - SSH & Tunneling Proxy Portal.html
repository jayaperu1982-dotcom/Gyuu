Initializing SSH & Wake-Lock on Android

                            

                                Android aggressively kills background processes when the screen turns off. Always acquire a Termux wake-lock and configure sshd to listen on port 8022 with password or public-key authentication.
                            

                            

                                

                                    STEP-BY-STEP SHELL SETUP
                                    
                                

                                
# 1. Prevent Android Doze from killing tunnels
termux-wake-lock

# 2. Check your current Termux username
whoami

# 3. Set a strong SSH password
passwd

# 4. Start OpenSSH daemon (default port 8022)
sshd

# 5. Verify daemon is listening
ss -tulpn | grep 8022

                            

                        


                        
                        

                            

                                
                                Common Termux Issues & Fixes
                            

                            

                                

                                    
ERROR: Permission denied (publickey,password)

                                    

                                        Ensure you ran passwd in Termux and are connecting with the exact output of whoami (e.g., u0_a245), NOT root.
                                    

                                

                                

                                    
ISSUE: Tunnel drops after 5 minutes of screen off

                                    

                                        Go to Android Settings → Apps → Termux → Battery → Set to Unrestricted. Also add ServerAliveInterval 30 to your SSH client config.
                                    

                                

                                

                                    
ISSUE: cloudflared fails to resolve DNS in Termux

                                    

                                        Run cloudflared with explicit edge IPv4 protocol: cloudflared tunnel --edge-ip-version 4 --protocol http2 --url tcp://localhost:8022
                                    

                                

                            

                        

                    

                


                
                

                    

                        

                            
Configuring DarkTunnel (SSH over WS + TLS)

                            

                                DarkTunnel wraps standard SSH connections inside an HTTP WebSocket handshake over TLS port 443. This makes your SSH session indistinguishable from normal HTTPS web browsing.
                            

                            
    
                                
  • 
                                    Tunnel Type:
                                    SSH + WebSocket + TLS (SSL)
                                
    • 
                                
  • 
                                    Server Host:
                                    your-subdomain.trycloudflare.com
                                
    • 
                                
  • 
                                    Server Port:
                                    443
                                
    • 
                                
  • 
                                    SNI (Server Name):
                                    your-subdomain.trycloudflare.com
                                
    • 
                                
  • 
                                    Local SOCKS5 Port:
                                    10808 (Enable Forward UDP)

                                Paste this into DarkTunnel's Custom Payload field if your backend uses a WebSocket-to-SSH bridge (like `wstunnel` or `node-ws-ssh`):

Xray-Core VLESS + WS Behind Cloudflared

                            

                                For maximum throughput and native multiplexing, run xray locally on port 10000 (non-TLS WebSocket) and let Cloudflare Quick Tunnel handle the outer TLS 1.3 encryption automatically.
                            

                            

                                

                                    RUN XRAY + CLOUDFLARED PIPELINE
                                    
                                

                                
# Install Xray-core in Termux
pkg install xray -y

# Launch Xray inbound server in background
xray run -c server_vless_ws.json &

# Expose local WS port 10000 via Cloudflare HTTPS
cloudflared tunnel --url http://localhost:10000

                            

                        


                        

                            
Client Connection Parameters (v2rayNG / Nekobox)

                            

                                

                                    Protocol:
                                    VLESS
                                

                                

                                    Address (CDN IP or Domain):
                                    *.trycloudflare.com
                                

                                

                                    Port:
                                    443
                                

                                

                                    Network / Transport:
                                    ws (WebSocket)
                                

                                

                                    Path:
                                    /nexus-ws
                                

                                

                                    TLS / Security:
                                    tls (AllowInsecure: false)
                                

                            

                            

                                Pro Tip: Because Cloudflare Quick Tunnels terminate TLS at Cloudflare's edge, set your Xray server inbound security to none while setting the client outbound security to tls.
